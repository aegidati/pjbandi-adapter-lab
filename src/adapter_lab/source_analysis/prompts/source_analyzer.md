# Source Analyzer Prompt Template

Use this prompt when experimenting with LLM-assisted source analysis in the future.

## Objective

Given a public funding source URL and a captured HTML sample, identify:

- likely source type
- recurring navigation patterns
- candidate detail link selectors
- attachment selectors
- pagination rules
- risks or anti-patterns that make extraction unreliable

## Output requirements

Return a concise structured response with evidence-backed observations and suggested adapter pattern fit.
